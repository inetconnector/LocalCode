Fixed Windows startup failures / Behobene Windows-Startfehler
--------------------------------------------------------------
PASS  All six .bat launchers are ASCII-only, BOM-free, and use Windows CRLF.
PASS  BUILD.bat is a small wrapper; build logic lives in scripts/build.ps1.
PASS  START.bat uses scripts/needs-build.ps1 and cannot bypass a required build.
