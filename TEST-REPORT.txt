LOCALCODE 6.4.2 - RELEASE VERIFICATION REPORT / PRUEFBERICHT

Reproduced user failures fixed
--------------------------------
- Coding-engine installer tests now use SetupDownloadsEnabled instead of the unrelated agent/web NetworkEnabled flag.
- Windows native build isolation no longer shadows per-test LOCALCODE_* directory overrides.
- Project-root repair and legacy-data migration tests explicitly control their highest-priority profile/config/cache paths.
- MCP resources use canonical file URIs; the parser also preserves Windows drive letters for file://C:/... and supports UNC authorities.
- Tests requiring a missing Aider executable isolate PATH from real user installations.
- Claude Code/OpenCode version and authentication probes no longer fail when the LocalCode app-data directory has not yet been created.
