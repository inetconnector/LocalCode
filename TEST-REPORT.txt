LOCALCODE 6.4.0 - RELEASE VERIFICATION REPORT / PRUEFBERICHT
=====================================================================

Fixed startup regression / Behobene Startregression
----------------------------------------------------
PASS  Automatic setup downloads are independent from agent/web network access.
PASS  Schema 9 -> 10 migration enables setup downloads while preserving the
      previous network_enabled preference.
PASS  Compact startup splash reports Ollama, model, and selected-engine setup.
PASS  Splash actions: retry, open log folder, limited mode, and exit.
PASS  Setup errors are localized; no generic network-disabled startup deadlock.

Additional fixes / Weitere Korrekturen
--------------------------------------
PASS  Only models required by the selected engine are pulled.
PASS  HTTPS Ollama URLs remain HTTPS; IPv6 hosts use valid bracketed addresses.
PASS  Disabled selected engines fall back explicitly to LocalCode native.
PASS  Splash server is loopback-only, token-protected, Host-validated, and uses
      bounded read/write/idle timeouts.
PASS  MCP uvx installation uses the pinned SHA-256-verified uv archive instead
      of executing a downloaded installer script.
PASS  STATE.md output distinguishes agent network from setup downloads.

Verification boundary / Verifikationsgrenze
--------------------------------------------
The release host is Linux. It executes source tests, coverage, vet, UI checks,
race-detector partitions, and Windows cross-builds. It cannot execute Windows
batch files or PE programs natively. The supplied executables are cross-build
artifacts from the final 6.4.0 source. dist/REBUILD-NATIVE.txt intentionally
forces START.bat to perform the complete native Windows build before first use.

Die Release-Umgebung ist Linux. Sie fuehrt Quelltests, Coverage, Vet, UI-Pruefung,

aus dem finalen 6.4.0-Quellstand. dist/REBUILD-NATIVE.txt erzwingt vor der ersten
