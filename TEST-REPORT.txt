Verification boundary / Verifikationsgrenze
--------------------------------------------
The release host is Linux with Go 1.23.2. It executes the complete source tests,
coverage, vet, UI test and race-detector partitions, and cross-compiles Windows
binaries. It cannot execute Windows batch files or PE programs natively. The
supplied PE files are cross-build artifacts from the final 6.3.0 source. The
mandatory REBUILD-NATIVE marker causes START.bat to rebuild them on the target
Windows computer. The user reported Go 1.26.5 there; BUILD.bat accepts supported
Go >=1.25 and otherwise downloads and verifies the current stable official release.

Die Release-Umgebung ist Linux mit Go 1.23.2. Sie fuehrt die vollstaendigen
Quelltests, Coverage, Vet, UI-Pruefung und Race-Detector-Gruppen aus und erstellt
Windows-Cross-Builds. Windows-Batchdateien und PE-Programme kann sie nicht nativ
starten. Die mitgelieferten PE-Dateien stammen aus dem finalen 6.3.0-Quellstand.
REBUILD-NATIVE.txt erzwingt auf dem Windows-Zielrechner einen nativen Neubau. Dort
wurde Go 1.26.5 gemeldet; BUILD.bat akzeptiert unterstuetztes Go >=1.25 und laedt
andernfalls die aktuelle stabile offizielle Version mit Pruefsummenpruefung.
