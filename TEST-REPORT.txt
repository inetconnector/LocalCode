Regression tests covering the reported failures:
- TestAgentContinuesAfterAskUserAnswer
  A user answer such as "ja" continues the stored conversation and does not restart the task.
- TestReadOnlyToolResultIsVisibleAsEvent
  File reads, listings, searches and Git reads publish their real result as a UI event.
- TestAskUserProducesOnlyOneVisibleQuestion
  A question is not duplicated in the event stream.
- TestSettingsEndpointAcceptsForwardCompatibleFieldsWhileAgentRuns
  Settings accept unknown future fields, preserve omitted values and save while a run is active.
- TestForceStopAlwaysReleasesUIState
  A forced reset always restores an idle, usable interface and invalidates the old run.
- TestControlAndOutputUIAreEmbedded
  Header/composer cancel controls, phase display, output list and model timeout setting are embedded.
- TestBackgroundWindowsCommandsUseNoWindowFlag
  Background commands use the Windows no-window process flag instead of flashing a DOS window.
- TestModelCallTimeoutReturnsControl
  A blocked model call is stopped by the configured deadline and the interface is released.
- TestStopAgentCancelsBlockedModelCall
  The normal stop endpoint cancels a blocked model request promptly.
