# LocalCode IDE extension handoff

Version 0.1.0. Parent repository branch: `codex/localcode-ide-extension`, based on `e511cc778e0e03ff1ba79ad4a18920844be33d8d` (master at work start, clean). Direct editing fallback explicitly selected because `aider_edit` is not exposed in this session. No pre-existing working-tree changes.

Architecture and security: see README; the parent backend owns all actual agent execution, permissions, persistence and recovery. Extension state persists only the selected task ID per workspace; draft text lives in VS Code webview state. It does not store credentials. Loopback HTTP goes through Node's native HTTP client, no proxy or redirects. CSP denies network access and arbitrary scripts; message actions are enumerated. File paths require canonical workspace containment. Remote/virtual/untrusted workspaces are disabled. Global executable/URL settings cannot be overridden by workspace settings. Built-in Git API is used for read-only HEAD/current diffs.

Backend changes: `/api/ping` advertises `stop-task-v1` and `steering-v1`; `/api/stop-task` atomically validates task/run identity before cancellation. `/api/steer` accepts bounded idempotent priority input during the ordinary agent loop. `agent_steering.go` owns the transient mailbox; `agent.go` drains it before inference and before action admission, cancels stale inference and rejects terminal-phase input. Active tools are allowed to finish. These routes are Desktop-only; Remote gains no new authority. Recovery remains single-journal and passive. Existing step/time budgets are not reset.

Verified so far (2026-09-06): Node syntax, DE/EN key parity, 5 Node behavior tests, focused Go race tests, Antigravity IDE 1.107.0 real Extension Host fixture integration, and Playwright/Edge DE/EN webview tests covering all visible actions and injection protection. Antigravity emitted pre-existing internal service/proposed-API warnings but the extension suite exited 0. npm audit after upgrading pinned dev tools to vsce 3.9.2 and ovsx 1.1.1 found 0 vulnerabilities. Full backend race/coverage/build, VS Code host test and publication are still running/pending; parent STATE.md will record final evidence.

Commands: `npm ci`, `npm run check`, `npm test`, `python scripts/test-webview.py`, `node scripts/test-host.js`, `npm run package`. For Antigravity set `LOCALCODE_TEST_IDE` to its absolute executable. Logs/screenshots live in the ignored parent `logs/` directory. Host suites use temporary directories and a fake HTTP service, not real model inference.

Limits: one shared active backend run; no remote workspaces; no inline completion; no claimed model/service parity. Streaming is LocalCode event streaming, not a claim that the underlying agent exposes token deltas. Steering is transient and can be rejected during startup/terminal phases; process crashes do not replay queued messages. Git diff review requires a repository at the chosen folder root; rename/delete cases compare HEAD to current content. Provider authentication and advanced settings remain in Desktop.
